# Prompt ảnh cho khu vườn — sprite cây & trang trí

Ảnh hiện tại được vẽ bằng `scripts/generate-crop-sprites.mjs` (`npm run assets:garden`). Muốn thay bằng ảnh AI: sinh theo prompt dưới, tách nền, thu về 256×256 WebP trong suốt và đặt đúng tên file trong `public/images/garden/`.
