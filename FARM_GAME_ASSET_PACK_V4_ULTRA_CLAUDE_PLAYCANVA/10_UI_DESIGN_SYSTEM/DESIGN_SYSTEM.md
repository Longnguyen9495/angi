FARM GAME DESIGN SYSTEM
=======================

Visual language
- isometric 3/4 top-down
- hand-painted cartoon
- clean but organic outlines
- warm daylight
- playful casual-game tone
- no SaaS/dashboard aesthetic

Suggested palette sampled conceptually from the master:
Sky: #58C8F2
Grass: #6FBE45
Deep grass: #3F8D35
Water: #18BFE6
Soil: #7A4C2C
Dark soil: #57341F
Wood: #9B642F
Roof orange: #D97A2D
Cream path: #EBD9A7
Gold: #F4C54E
UI white: #FFFDF6
UI dark: #4A3A2A

UI:
- rounded but not overly modern
- warm wooden/painted surfaces
- soft shadow
- strong readable icons
- compact HUD
- avoid huge modal cards covering the farm

Interaction states:
DEFAULT: normal
HOVER: +small scale / highlight
SELECTED: bright outline
PRESSED: tiny scale down
DISABLED: reduced opacity
SUCCESS: sparkle + bounce
ERROR: subtle shake

Lighting:
Primary light from upper-left.
Shadows generally fall down/right.
Keep lighting consistent across all reconstructed layers.
